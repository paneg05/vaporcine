Importante para HLS no Firebase Storage:

Para que um stream HLS seja reproduzido corretamente (não apenas o manifesto principal `master.m3u8`, mas também os manifestos de mídia e os segmentos de vídeo `.ts`/`.mp4`), você **DEVE** configurar as Regras de Segurança do Firebase Storage para permitir leitura pública (ou acesso autorizado adequado) para **TODOS os arquivos no diretório** onde o seu stream HLS está armazenado.

A URL de download obtida acima é para o arquivo `master.m3u8` específico e seu token de acesso. O player HLS fará requisições subsequentes para os outros arquivos HLS com base nas referências do manifesto principal. Essas requisições precisarão ser permitidas pelas suas Regras de Segurança.

Exemplo de Regra de Segurança para um diretório público HLS (substitua `seu-diretorio-hls` pelo caminho real): 

rules_version = '2';
service firebase.storage {
  match /b/{bucket}/o {
    match /seu-diretorio-hls/{allHlsFiles=**} {
      allow read; // Permite leitura pública para todos os arquivos HLS
    }
    // Mantenha outras regras para o restante do seu bucket conforme necessário
    match /{allOtherPaths=**} {
      allow read, write: if request.auth != null;
    }
  }
}
